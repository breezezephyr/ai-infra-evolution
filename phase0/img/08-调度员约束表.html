个人进化 · Phase 0 复习

三篇合起来，
是调度员的约束表

左边是三篇算出来的事实，右边是引擎每一圈要遵守的规则。Phase 1 学的就是右边。
93% 在跑圈
→
优化重心在 decode；多坐人是唯一分摊手段
搬行李和跑圈互不相干
→
站台上搬大件会拖慢全车 → chunked prefill / PD 分离
一圈油钱固定
→
调度员的目标：座位不空（continuous batching）
人数 × 行李 ≤ 座位
→
每圈的准入条件；满了请人下车（抢占）
新车出库 1–2 分钟
→
准入控制 + 预热车队，别指望临时出车
按箱寄存，前箱一变后箱全废
→
常客上同一辆车（cache-aware 路由）
寄存只省搬不省跑
→
命中率高 ≠ 吞吐高，吞吐看坐几人
三篇算的是「跑一圈多少钱、坐几人、寄存省多少」；调度员管的是「每一圈让谁上、谁下、谁先搬」。
