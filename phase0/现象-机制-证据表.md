# Phase 0 · p0-1 现象 → 机制 → 客户端证据

> 看板那张表是两列。真正有用的是三列：中间多一列「我怎么从客户端证明它」。没有第三列是知识点复述，有了第三列就是 Phase 2 的压测大纲。
> 每条现象只对应一个主机制；证据必须是不改服务端就能拿到的：时间戳、响应头、usage 字段、重复实验。

## 一、看板上的七条，补第三列

| # | 调用方看到的现象 | 主机制 | 客户端证据（怎么证明） | 公交车 |
|---|---|---|---|---|
| 1 | 首字等很久，后面吐得快 | prefill 算力密集、decode 带宽密集，两段正交 | 同一并发下 prompt 翻倍，TTFT 近似翻倍、TPOT 不变；`max_tokens=1` 的请求端到端 ≈ TTFT | 搬行李慢，跑圈匀速 |
| 2 | 长 prompt 又贵又慢，system prompt 每次都一样 | KV cache + prefix caching 按 block 复用 | `usage.cached_tokens`（各家字段名不同）非零且为 block 大小整数倍；同前缀第二次请求 TTFT 明显下降，TPOT 不变 | 常客行李已寄存 |
| 3 | 高峰期变慢、返回 429 | 排队 / continuous batching 让 batch 变大 / 按 token 限流 | 拆成三条：① 输入不变、TTFT 随时段变 → 排队；② TPOT 随时段变 → 车上人多了；③ 429 带 `x-ratelimit-*` 头且 `remaining` 归零 → 桶用尽，不带 → 服务过载 | 站台排队 / 车坐满 / 售票口限购 |
| 4 | 同样的请求有时快有时慢 | noisy neighbor：同 batch 里有人在 prefill 长输入 | 流式 chunk 间隔出现**周期性**顿（> 3× 中位数），网络抖动是随机的、这个是规律的 | 中途有人上车搬大件，全车等 |
| 5 | 流式输出中途断掉 | 抢占（KV 满了被踢）/ 长连接超时 / 审核截断 | `finish_reason` 是 `length` 还是 `content_filter`；无 finish_reason 直接断 → 连接层；断前 TPOT 是否已明显拉长 → 车快满了 | 被请下车 |
| 6 | 定价表里 cached input 打折 | 缓存只省 prefill，decode 一分不省 | 同一请求命中 vs 未命中：TTFT 差 ≈ 折扣对应的那段，TPOT 完全一样；账单里 output 单价不变 | 省搬不省跑 |
| 7 | 语音对话回合间有一拍停顿、打断没反应 | 实时会话的延迟预算 + barge-in 全链路取消 | 录 turn latency：用户说完 → 首个音频帧；打断后 TTS 停止的延迟 | 车门关了才能改站 |

## 二、补三条：Agent 场景特有

| # | 现象 | 主机制 | 客户端证据 | 公交车 |
|---|---|---|---|---|
| 8 | tool call 返回后的下一轮，有时特别快 | 上一轮的 messages 是这一轮的前缀，全部命中 prefix cache；只有 tool 结果那几百 token 要 prefill | 第 N 轮 `cached_tokens` ≈ 第 N−1 轮的 total_tokens；TTFT 与 tool 结果长度线性、与总上下文无关 | 常客加了一件行李又上车 |
| 9 | 并发发 5 个子任务，总有 1 个明显慢 | 桶用尽（第 5 个撞 `remaining=0` 排队）或落到了不同实例（prefix 没命中） | 看 5 个响应的 `x-ratelimit-remaining`：递减到 0 → 桶；都有余量但其中一个 `cached_tokens=0` → 打到别的车上了 | 五个人挤一个售票口 / 上错了车 |
| 10 | 长对话到某一轮之后突然每轮都慢 | 上下文过长，prefill 主导；或触发了服务端的上下文压缩 / 截断，缓存全废 | TTFT 随总 token 线性涨到某个拐点后跳变；拐点处 `cached_tokens` 突然归零 → 截断毁了前缀 | 行李越带越多；到某站被要求重新打包 |

## 三、这张表怎么用

- 第三列每一格就是 Phase 2 的一个压测用例。现在先不测，先把这些字段**记进日志**：`cached_tokens`、`finish_reason`、`x-ratelimit-*`、`openai-processing-ms`、每个 chunk 的到达时刻。
- 三条 Agent 特有的现象是做 Agent 的人才会遇到的——纯 SRE 背景转过来的人没这份体感，这是「护城河」那一列的素材。
