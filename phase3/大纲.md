# Phase 3 · 架构翻译：四个旋钮，线上谁来拨

> 第 9–12 周。P2 的收尾是一张表：四个旋钮（并发、每圈预算、寄存箱、座位数）各只动生命周期图上一两个节点。P3 回答的是下一个问题：**线上多台车、多种乘客时，这个旋钮由谁来拨，拨错了怎么兜住。** 后端做过的限流、优先级、亲和路由、容量规划，逐个搬到 LLM 约束下，看哪里失效、怎么改。
> 教材：ai-infra-book 第 9 章《分布式推理》9.2 / 9.5 / 9.6 / 9.7，第 8 章 8.6，第 11 章 11.3 / 11.4。
> 产出：四份一页纸（每份一张图卡）、三组小实验、四篇文章 P3·1–P3·4。

## 一、主线：四个旋钮挂六个主题

| 篇 | 旋钮（P2 实测事实） | 后端老问题 | 挂上的主题 | 教材 |
|---|---|---|---|---|
| P3·1 | 并发：13K 座位 ≈ 10 人；并发 16→32 吞吐同为 37x tok/s，TTFT 1.8 s→14.8 s | 限流、准入、排队反馈 | **限流**（按 token 预算而不是 QPS；多放人只加排队）+ **流式超时**（首字超时与字间停滞是两种超时，兜底不同） | 8.6、11.3 |
| P3·2 | 每圈预算 2048：同批 4 人 2 人先出首字、2 人晚一圈；8192：TTFT 一样、ITL p99 随行李线性涨 | 优先级队列、QoS 分级 | **多租户降级**（交互 vs 批处理谁先出首字；满车先降谁；vLLM priority 调度） | 11.3、11.4 |
| P3·3 | 寄存箱开：TTFT ÷14，KV 87%→29%，抢占归零；只在同一辆车上有效 | 一致性哈希、亲和路由 | **cache-aware 路由**（T_first = max(Q, R) + C；多车之间寄存箱不共享，路由决定命中率；带宽交点 1.41 / 6.3 GB/s） | 9.5 |
| P3·4 | 座位数：GPU_UTIL 0.90→0.80 running 上限降、抢占少而小、排队代替抢占 | 容量规划、拆读写 | **PD 分离**（用自己的 300 µs/token 和 15 ms/圈算 P:D 配比与收益边界）+ 扩容排空 T_drain = λT_s/(μ−λ) | 9.2、9.6.1、9.7 |

**灰度评测不单独成篇**：变成每份一页纸的固定最后一栏「怎么验」——拨了这个旋钮后盯哪两条线、对照组怎么设、什么信号算失败要回滚。P2 的两面对上是它的雏形。

## 二、一页纸模板（四份同构）

每份一页纸四栏，做成一张图卡：

| 栏 | 内容 | 例（P3·1） |
|---|---|---|
| 老做法 | 后端里我们怎么做 | 网关按 QPS 限流，超了 429 |
| 哪里失效 | LLM 约束下哪条假设不成立，指回 P2 哪组数 | 一条请求占的资源是 token 数不是条数：exp2 里 6K 输入一条 = 256 输入二十几条 |
| 新方案 | 约束下的做法，被否决的划掉 | 按 in+out token 预算准入；~~按连接数~~ |
| 怎么验 | 灰度指标、对照组、回滚信号 | 对照：网关拒绝 vs 站台排队；看 TTFT p99 与拒绝率；waiting 持续 > N 回滚 |

## 四、四篇文章骨架

统一结构：开头一段接 P2 的那组数 → 一页纸图卡 → 实验图（P3·4 为算表）→ 带走的一条 → 几个可以讨论的问题 → 附读了什么。

**P3·1 ｜ 站台限流：按人数还是按行李**
1. exp1 回看：并发 16 与 32 吞吐相同，多出来的人全在站台
2. 一页纸：限流从 QPS 到 token 预算
3. 两种超时：首字超时（排队 + 搬行李）与字间停滞（被请下车重搬），兜底动作不同
4. exp5：拒绝 vs 排队
5. 讨论题

**P3·2 ｜ 谁先出首字：交互与批处理同车**
1. exp2 回看：预算 2048 下同批 2 人晚一圈——调度器不知道谁是谁
2. 一页纸：多租户降级
3. 降级顺序：满车先减批处理的预算、再拒新批处理、再抢占（P1 决定 3）
4. exp6：FCFS vs priority
5. 讨论题

**P3·3 ｜ 寄存箱在哪辆车上：cache-aware 路由**
1. exp3 回看：命中让 TTFT ÷14，但只在一辆车上
2. 一页纸：从一致性哈希到亲和路由，T_first = max(Q, R) + C
3. 命中 vs 均衡的冲突；带宽交点：什么时候跨车搬寄存箱比重搬划算
4. exp7：round-robin vs 前缀哈希，双实例
5. 讨论题

**P3·4 ｜ 拆车：PD 分离与这张卡的配比**
1. exp4 回看：座位少了，排队代替抢占；座位是搬行李和跑圈共用的
2. 一页纸：PD 分离——搬行李的车和跑圈的车分开
3. 用自己的数算配比与收益边界；KV 传输 48 ms 量级在这张卡上是多少
4. 扩容：从车库出新车的排空时间 T_drain
5. 讨论题 + Phase 3 收尾表：四个旋钮线上由谁拨
