# exp18 结论：体验有分母，成本有分母

日期：2026-10-23。依据前四组原始记录离线重算，另有一次 CUDA ASR/LLM 常驻补测。原始输入哈希、字段合约、重放命令见 [运行说明](../exp18/README.md)。

## 1. 不把独立实验拼成一场会话

| 来源 | 本次保留的分母与结论 |
|---|---|
| exp14 | 正式 108 条，三组各 36；虽然都 stop，完整端点仅 30/36、27/36、27/36，提前端点分别 6/9/9。完整回合首 PCM p50 约 1837/1385/1396 ms，从客户端冻结输入的离线能量参考结束计；另有浏览器 n=3 渲染代理，声学输出未知 |
| exp15 | 最终媒体 24 条，按路径/场景各 n=6；WS underrun 和 RTC concealedSamples 各用自己的定义。RTC 起始 inbound 缺项，不能虚构区间增量。实际浏览器排空 n=1，收到 producer_done 到 finished 通知 654.7 ms |
| exp16 | 浏览器 18 条双轮记录，各策略/插话点 n=3。server_only 旧音频尾巴 p50 1890～1940 ms，full 为 0 或 2.667 ms，是渲染帧位置；服务器 stop→join 另用同域时钟算。full 的受控旧帧 9/9 拒绝，新轮 18/18 完整渲染；没有自动证明语义质量 |
| exp17 | 正式 36 个 GPU 回合；输入供给完成到有效文字的时长只覆盖该文字链路，不含 TTS/播放；三策略不能因整体时差推导提前生成收益 |

各项不能相乘得到生产成功率，分位数不能相加，服务器和浏览器时钟不能直接相减。800 ms 为系列探索目标；SLO 生产目标比例、报告窗口、质量标准、真实联合会话观察仍为未知。见 `exp18/metric-contract.json`。

按“端点完整、自然结束、哈希/样本完整且无错误、参考结束到首 PCM 非负且不超过 800 ms”的同一规则，A/B/C 分别 0/36、6/36、6/36；全体为 12/108，未知 0。不能写成所有首包均未达 800 ms。另测的浏览器 3 条非静音渲染代理均超过 800 ms，且不并入前述分布。

## 2. 三种分钟

从 exp17 每回合 source.run_start_ns 到该回合 all_workers_joined，重算正式实验：

| 指标 | 数值 | 范围 |
|---|---:|---|
| 输入音频 | 205.380 秒 / 3.423 分钟 | 含静音；四条文件各重放 9 次 |
| 实验回合窗口之和 | 230.781056 秒 / 3.846351 分钟 | 每回合供给开始到线程退出 |
| 同卡回合区间并集 | 230.781056 秒 | 本批串行，未重叠 |
| 正式批次模型常驻窗口 | 232.190973 秒 / 3.869850 分钟 | 首回合开始至末回合 join；ASR+LLM 由同一进程保留 |
| 已标注全零静音 | 42.570 秒 | 13.50 秒插入停顿、29.07 秒尾静音；逐 WAV 验证 |
| 真实用户会话分钟 | null | 没有真实多轮用户会话或负载测试 |

常驻窗口不含载入、热身、窗口外驻留。零 PCM 静音时，识别/草稿仍可能在执行，不能当成 GPU 无请求时间。437 次正式窗口内全卡显存采样为 1939～2235 MiB；采样峰值不等于精确逐请求峰值，利用率不能还原精确 GPU kernel 时间。

## 3. 重算与废稿

各组 n=12，原始输入均为 68.46 秒。token 计数含 EOS；“被选”指最终 generation，不是语义质量验收。

| 策略 | ASR 次数 | 累计前缀音频秒 | LLM 稿数 | 总 token | 废弃 token | 被选 token | 被选稿提前开始 |
|---|---:|---:|---:|---:|---:|---:|---:|
| endpoint | 12 | 68.46 | 12 | 291 | 0 | 291 | 0/12 |
| eager | 93 | 351.66 | 78 | 1367 | 1079 | 288 | 12/12 |
| stable2 | 93 | 351.66 | 12 | 291 | 0 | 291 | 0/12 |

累计前缀音频不是 GPU 执行时间或价钱倍数。stable2 本批没有提前开始的选中稿，整体文字就绪差异不能直接归因于预生成；ASR 等待等路径不完全一致。实际 stale piece 拒绝没有触发，仍保留原实验机制测试的独立证据，不虚报运行中拒绝了旧结果。

## 4. 新增常驻窗口 n=1

硬件为 NVIDIA RTX 4060 Laptop 8188 MiB。ASR 为 CUDA INT8/FP16，LLM 为 CUDA BF16；无 TTS。新增 ASR、LLM 热身各一次；CUDA 同步后，本实验不再提交新推理请求，模型对象留在进程中。

- 实际观测 10.389485 秒，37 次 nvidia-smi 查询，查询起止均保留。
- 全卡显存 1933 MiB，37/37 相同；热身前为 342 MiB。
- GPU 利用率读数为 40% 一次，随后 0% 共 36 次；不等于精确设备活跃秒数，也不证明其他进程无活动。
- 该样本说明此窗口无新实验请求但模型仍占显存。不能从 n=1 推导并发容量、普遍空闲占用或生产价格。
- 结束后独立 SSH 核对：本脚本进程为 0，gpu-router active，显存 342/8188 MiB，利用率 0%。无新增服务/隧道。

## 5. 只演算已知分母，不伪造实际账单

常驻 GPU 项／会话分钟 = 同范围常驻 GPU 小时 × 明确费率 ÷ 真实会话分钟。共享设备的驻留区间取并集，多张设备分别计。

以**自定假设 R=2 元／GPU·小时**演算正式窗口：GPU 项 0.128994985 元；除以实验回合分钟为 0.033536978 元／实验回合分钟。该费率不是市场报价或实付；该分母不是真实会话分钟。实际每会话分钟成本、实际账单均为 null。

载入、热身、窗口外等待、CPU/内存/网络/存储/API 费用未包含。没有并发容量实测，也没有声学首声、麦克风起音或质量达标分钟。因此不能据此报生产单价，不能把输入、回合或常驻分钟互换。
