# exp18：体验与资源分别记账

日期：2026-10-23。前四组实验已完成；本轮重算冻结原始记录，不把不同实验拼成一场生产会话。

## 范围

1. exp14：完整端点与终态分开；从同域时间戳重算首 PCM、800 ms 探索目标及浏览器渲染代理。
2. exp15：24 条媒体回放按路径/场景分组；WS 欠载与 RTC concealment 保持各自定义；实际浏览器排空另列 n=1。
3. exp16：按音频帧位置算旧音频渲染尾巴；服务器同域停止信号到线程退出；新轮完整播放与迟到旧帧隔离分别统计。
4. exp17：36 条 GPU 回合重算输入音频、重复 ASR 前缀、LLM 废稿及正式批次常驻窗口。输入中的零样本静音不能当成无推理请求时长。
5. 补一个 n=1 的 ASR+LLM CUDA 常驻观测：各热身一次，CUDA 同步后，本实验不提交新请求，目标约 10 秒。逐次记录 nvidia-smi 查询区间与全卡显存/利用率；其他进程可能使用 GPU，不宣称全设备空闲。进程正常结束并独立核对退出。

## 核算规则

- 每项写起点、终点、时钟、单位、适用分母、成功/失败/未知。缺测保留 null。
- p50/p95 用有测量值的样本线性插值，同时保留 eligible/measured/unknown；不加分位数，不跨机器直接相减。
- GPU 常驻计同一设备上的区间并集；不按 session 重复相加。正式批次窗口从首回合开始到末回合工作线程全部退出，不包含载入、热身和窗口外常驻。
- 回合秒数、输入音频秒数、真实用户会话分钟、GPU 常驻秒数各自保留。本轮真实会话分钟未知，不能给实际每会话分钟成本。
- 废弃 token 含生成器记录的 EOS。采用的 generation 不等于通过语义质量验收。
- 费率 R 是自定假设，不是报价、账单或部署成本。示例只算常驻 GPU 项；CPU、网络、存储、API 等未测项保留未知。
- 本轮没有麦克风起音、声学回环、真实多用户会话/并发容量或付费账单。候选 SLO 合约是设计产物，不宣称生产达标。
