# Phase 3b · 容量、缓存与合规：服务体系的另一半

> 第 13–15 周。Phase 3 管的是「一排车在跑的时候」：门、优先级、选车、拆车。3b 管「车之外」：车库里什么时候出新车、出一辆要多久、停车时车上的人怎么办；有没有不用上车就能给的答案；每一趟的账记在谁头上；车上说错话了怎么截住、谁在薅车。

## 二、小动手（只做 DARYU 上能做的）

环境沿用 P3：`bench-vllm` Qwen3-1.7B :8003，网关 `gw.py`，客户端 `mix.py`。**新资源：现网 `qwen3-embedding` :8001 本来就在跑**，语义缓存直接用它，不用另起。

| 篇 | 实验 | 看什么 | 先算的预期 | 代价 |
|---|---|---|---|---|
| P3b·1 exp8 冷启动 | 同一辆车起 5 次，拆时间线：进程 → 读权重 → torch.compile → CUDA graph → 就绪。对照：页缓存冷（drop_caches）/ 热；compile 缓存有 / 无；`--enforce-eager` | 每段秒数；哪段能被预烤 / 缓存 / 常驻压掉 | P3·4 实测总 43 s；权重 3.2 GiB 从 NVMe 读 ≈ 2 s，热缓存 < 1 s；大头应在 compile + graph | 低，只是重启 + 读日志 |
| P3b·1 exp9 扩容信号 | 网关前放一段爬坡负载（λ 从 0.5 到 2 × μ），同时记 waiting、waiting 斜率、TTFT p99、GPU 利用率；离线算每个信号「比 TTFT 超 SLO 早多少秒报警」 | 各信号的提前量 vs 误报；配合 exp8 的 43 s 看哪个来得及 | GPU 利用率一开始就饱和、没提前量；waiting 斜率比绝对值早 | 中，复用 mix.py 加爬坡 |
| P3b·1 exp10 排空 | 网关加 drain：停收新请求 → 等在途 → 上限 T 后断开。流式长输出（2K）下量：排空要多久、被断的人输出到第几个字 | 排空时长分布；断开的浪费（已跑圈数） | 在途最长一条 ≈ 2048 × 21 ms ≈ 43 s | 低 |
| P3b·2 exp11 语义缓存 | 网关加一层：prompt → embedding :8001 → 最近邻 → 相似度 ≥ θ 直接返回旧答案。数据：~100 个 FAQ 问题，每个用 1.7B 自己改写 5 种说法 + 20% 「看着像、意思不同」的对抗改写 | θ 扫 0.80–0.98：命中率、答错率（命中但原题不同）、省下的 GPU 秒、embedding 自己的延迟 | embedding 一次 ~10 ms；θ 高到答错 < 1% 时命中应掉到一半以下 | 中，要造数据集 |
| P3b·3 exp12 账本 | exp7 引擎窗口计数按示例费率落账；旧日志缺 tenant/逐请求 usage，不生成真实租户账，另用显式手写样例验合同。生成流重叠时间按一张卡分摊代理。exp5 queue 回放近似排位 → 等待，超时单列 | cached 打折后账单差多少；等待预估误差 p50 / p90 | 预估 = 位置 ÷ μ；FCFS 下误差应在 ±30% | 低，全离线 |
| P3b·4 exp13 流式审核 | 独立门控按句切窗；GPU真实0.6B生成＋真实embedding/0.6B分类审核，命中后截断；CPU/已知标签回放另存 | 首段与可见批次间隔、偏移对齐的已漏出字符；误拦/漏判；实际生成停止原因 | 历史预期：每句+10–30ms、异步漏1句；已用GPU独立测时和30条真实路径校正，见exp13结论 | 中 |

## 三、四篇骨架

统一结构：开头接一个 P2 / P3 的数 → 一页纸图卡 → 实验图 → 带走的一条 → 几个可以讨论的问题 → 附。

**P3b·1 ｜ 车库：出一辆新车要多久**
1. P3·4 回看：利用率 90% 时重启 43 s，站台七分钟才清空
2. exp8：43 s 拆成几段；预烤、缓存、常驻各压掉哪段（技术版 02 五级台阶对上）
3. exp9：扩容信号——CPU / GPU 利用率为什么没用，waiting 斜率提前多少
4. exp10：停车时车上的人——排空上限、被断的人怎么办
5. 多机房一节纸面
6. 讨论题

**P3b·2 ｜ 不上车的答案：语义缓存**
1. P2 exp3 回看：寄存箱省的是搬行李，语义缓存省的是整趟车
2. 一页纸
3. exp11：阈值曲线——命中率 vs 答错率
4. 准入规则：带用户记忆 / 个性化 / 时效性的请求一律不进；模型或 prompt 版本变更全量失效
5. 讨论题

**P3b·3 ｜ 账本：一趟车记在谁头上**
1. P3·3 回看：轮询 / 哈希的延迟差异；exp12 在示例费率下对每千次完成比较账单
2. 一页纸：成本 = prompt × 单价 + cached × 折扣价 + output × 单价；GPU 秒怎么分摊
3. exp12：窗口总账与显式租户样例；cached 打折落账，缺字段的真实分账留空
4. 排队反馈：预估等待能多准
5. 讨论题

**P3b·4 ｜ 车上说错话：流式审核与滥用识别**
1. P3·1 回看：两种超时杀两种人；审核截断是第三种
2. 一页纸
3. exp13：同步审 vs 异步审，首段/可见间隔、漏出字数与判定正确性
4. 滥用画像：一页规则表
5. 讨论题 + 3b 收尾表
