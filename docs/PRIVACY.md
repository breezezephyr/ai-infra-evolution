# 公开范围与隐私

本仓库 ai-infra-evolution 是新整理的公开副本。原始私有源材料不进入 Git；
仅纳入完成公开审查、脱敏并确认有权公开的副本。文章、配图、代码与实验记录保留相对目录，公开前检查连接信息与个人信息。

## 忽略与脱敏

.gitignore 仅用于排除本地文件，不等于脱敏，也不能移除已经被 Git 跟踪或进入
历史记录的内容。不要把真实密钥、地址、账户或其他秘密写进忽略规则；规则只写
路径和模式。发现泄露时应撤销或轮换凭据，并另行处理相关文件和历史记录。

本地环境文件、私有目录、连接配置、发布产物和公众号回执不公开。
.env.example 只使用 loopback、example.invalid、示例账户和空密钥。
phase0/*.csv 是原始业务 CSV，排除在公开范围外；其他实验 CSV 按内容逐项审查，
不因扩展名自动排除或视为可公开。保留经检查的实验 HTTP 记录；435 个 WAV 与 10 个 PCM 音频文件的字节暂不分发，
其音色输出的分发许可尚未单独确认，详见 [复现说明](REPRODUCIBILITY.md)。

## 数据与实验记录

- 数据脱敏副本可能与原始数据具有不同的字节内容和哈希；原始数据哈希不能作为
  公开副本的完整性校验值。需要校验时应明确哈希对应的具体副本。
- 历史测量按当时的环境、输入和记录说明；整理、导出或脱敏不等于重新运行实验，
  不声称历史结果已经重跑或复现。
- Notebook 公开前移除全部运行输出，并检查单元格、附件和元数据中的敏感内容。
- 合成 fixtures 只有在来源、生成方法和公开依据可追溯时才可公开；“合成”标签
  本身不能证明不含私有样本、个人信息或第三方受限内容。
