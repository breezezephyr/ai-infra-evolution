## 版本、来源及其证明边界

- Python **3.12.10**；deepseek-recipe **0.2.0**；pytest **8.4.2**。完整平台和版本在 `formal-v1/environment.json`。
- recipe 对照源码固定为 `935817c66f5d6e64838f419692545f06787e485f`；DeepInfer 固定为 `9bd9cf243fc53ef9afbf8f04d391d989117d6ab9`。
- 当前安装 native `.so` 与现有 wheel 内的 native 成员逐字节 SHA256 一致；安装的 `.pyi` 与固定源码 `.pyi` 逐字节一致。**没有 native 构建 commit 的独立证明**，不能把 wheel 版本或 stub 一致说成二进制构建 revision 已证明。
- `vendor/exp21-source/sources.json` 记录每份官方 fixed raw 文本的 URL、获取时间、字节数、SHA256、本地计算的 Git blob SHA1。共 **20 份、305,036 字节**：18 份下载，2 份从现有 minimal 副本复核复制。三条探测错误路径的 404 也原样保留。
- 当前对两个 commit 的 GitHub tree API 查询及带不同查询参数的重试均返回 **403 rate limit exceeded**，记录在 `tree-verification.json`。因此 `git_tree_match=null`；不能把本地算出的 blob hash 说成已获 Git tree 独立认证。两份旧文件与既有 manifest 的 SHA/Git blob 相同，历史 tree 核对状态单列，不冒充本次认证。

## 声明 → 转换 → 后端映射矩阵

下面的“映射”是本实验的保守候选/拒绝策略；没有实现 recipe→DeepInfer 传输，更没有执行 compiler。逐条 126 行及完整 kind/schema/error 见 `formal-v1/mapping-matrix.csv`、`records.jsonl`。

|---|---|---|---|---|
| 三协议无工具、无格式 | `OutputConstraint=None` | 不设置 so_args；未传输 | 未执行 | 未执行 |

## Parser 反例的证据边界

18 条正式探针都使用合成 backend 文本、真实 StreamProcessor 和协议 accumulator，原始 events/response/text 保存在 `parser-probes.jsonl`，每条都写明 `sampling_executed=false`、`schema_instance_validated=false`，没有伪造 token 计量。

- strict response schema 的 10 条反例（两协议 × wrong type / missing required / extra property / 非 JSON / 数组）全部被 parser 原样转发。字面值真假由冻结 fixture 的人工反例标签给出，未执行通用 JSON Schema 实例 validator。
- Chat/Responses json_object 的 `[1,2]` 都被保留且可 json.loads，足以反驳“转换接受就保证输出是 object”。`not JSON` 在 json_object parser 下变成一个空格且未报错，json.loads 仍失败。
- Chat regex 的不匹配文本被转发；Messages 的被忽略格式也不会凭空约束文本。JSON 能解析、符合 schema、业务答案正确仍是三个独立指标。

## 候选实测不变量

| 候选 | 满足/适用 |
|---|---:|
| CPU 记录从不声称采样/compiler/实例验证/工具执行 | 126/126 |
| 工具 constraint 数组与转换后工具名、required 初态一致 | 27/27 |
| 工具 kind 不直接转发给 DeepInfer compiler | 27/27 |
| 空 JSON sentinel 不作为空 schema 转发 | 4/4 |
| none 选择移除工具定义和工具约束 | 20/20 |
| Messages 的格式字段探针保持 text 且无约束 | 15/15 |
| strict schema 保留原 prompt schema、单独规范化 constraint | 2/2 |
| 已识别非法 schema 在转换阶段拒绝 | 8/8 |
| strict-schema 输出反例经过 parser 仍不构成实例验证 | 10/10 |

这些不变量只适用于固定版本、固定输入和本实验记录器；不能外推为所有 schema、所有模型、所有 parser 边界或 DeepInfer 实际采样保证。
