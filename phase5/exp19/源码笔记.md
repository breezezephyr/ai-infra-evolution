# exp19 源码笔记：入口到模型输入

固定阅读版本：`935817c66f5d6e64838f419692545f06787e485f`。本页串起请求侧接口，不覆盖输出解析器或引擎执行。所选源码哈希见[来源记录（第三方依赖需恢复，未随仓库收录）](../../docs/THIRD_PARTY.md)；执行的是独立登记的0.2.0发行wheel。

## 实际调用链

```text
冻结输入与每条独立ConversionOptions
  → ChatCompletionRequest / ResponsesRequest / MessagesRequest
  → .convert(options)
  → ConversationRequest
      ├ model_version、stream
      ├ conversation
      ├ inference_options
      └ parsing_options
  → 按model_version选DeepseekV4Encoding / DeepseekV41Encoding
      ├ render_conversation(conversation) → prompt + special_ranges
      └ with_tokenizer(匹配版本).encode(conversation) → token IDs
  → resolve_max_tokens(实际输入token数, 调用方传入的上下文上限)
  → 调用方将输入与设置交给后端（本轮未执行）
```

本地真实调用在[run.py](run.py)的`configured`、`snapshot`与`run_case`，不是自行实现上述协议转换。三协议差异发生在转换层；special_ranges和实际token IDs由库生成。

## 交接对象与责任

| 对象 | 应保存的内容 | exp19对应检查 |
|---|---|---|
| ConversionOptions | 默认thinking、模型别名、web_search处理方式 | 每条新建；默认、显式覆盖、未注册模型分别测 |
| Conversation | 角色/内容、历史reasoning、工具声明、thinking/effort及格式要求 | 比较选定事实；允许的协议差异先声明 |
| InferenceOptions | max_tokens、采样设置、输出约束描述 | 检查默认、归一化、截断；未做约束采样 |
| ParsingOptions | thinking初态、工具解析开关、停止串 | stop差异与prompt/token等价分别核对 |
| prompt / special_ranges | 可读模板文本与显式控制区间 | 普通原文拼写不能自动取得模板控制身份 |
| tokenizer / token IDs | 版本文件哈希、实际编码序列及数量 | 加载前校验内容；逐族比较实际ID，未以字符数估算 |
| resolved max_tokens | 编码后输入长度、传入上下文参数、函数结果或错误 | 显式上限、默认预算、余量与边界分开记录 |

Python接口见[固定stub](https://github.com/deepseek-ai/deepseek-recipe/blob/935817c66f5d6e64838f419692545f06787e485f/deepseek-recipe-python/python/deepseek_recipe/_native.pyi)，Rust请求公共类型和预算函数见[request/mod.rs](https://github.com/deepseek-ai/deepseek-recipe/blob/935817c66f5d6e64838f419692545f06787e485f/deepseek-recipe/src/request/mod.rs)。

## 本轮保留的约束

- 请求相似不预设等价。prompt、token IDs、生成设置与解析设置分别比较，相同的prompt/IDs不能覆盖停止串差异。
- 输出上界检查与编码后上下文检查属于不同阶段。`resolve_max_tokens`的上下文值由调用方传入；其结果不是模型容量实测。
- 使用相应DeepSeek编码规则和tokenizer。别名只是版本映射，不使其他模型获得兼容能力。
- 编码需要特殊区间。Python下标为Unicode字符下标，Rust原始区间使用UTF-8字节偏移，跨语言不能直接复制数字。依据见[tokenizer指南](https://github.com/deepseek-ai/deepseek-recipe/blob/935817c66f5d6e64838f419692545f06787e485f/docs/tokenizer.zh.md)。
- 库转换工具和约束声明；实际推理、工具执行、HTTP/SSE、取消和usage账本由后续接入继续核验。

源码预期与实测差异逐条见[fixture-notes](fixture-notes.md)、[最终结论](../results/exp19-结论.md)。当前结论限定在固定版本与冻结输入，不外推为完整协议兼容性保证。
